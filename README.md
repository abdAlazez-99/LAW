## 📖 Overview

**LAW** is a clean, authoritative web template designed for legal practices and corporate attorneys. Built strictly with **semantic HTML5** and **modular CSS3**, the project demonstrates how rich layout architecture, responsive grids, custom utility classes, and interactive components (such as an expandable FAQ accordion) can be achieved with **zero JavaScript dependencies**.

🔗 **Live Demo:** [https://abdalazez-99.github.io/LAW/](https://abdalazez-99.github.io/LAW/)

---

## ✨ Key Features

- **Pure HTML & CSS Architecture:** Fully functional and interactive without a single line of JavaScript.
- **Native Interactive FAQ Accordion:** Powered by semantic HTML5 `<details>` and `<summary>` elements with smooth custom styling.
- **Modular Custom CSS Framework:** Separates reusable design tokens, variables, and utility classes (`framework.css`) from page-specific styles (`style.css`).
- **Performance-Optimized Local Typography:** Self-hosted **EB Garamond** (Variable Font) and **Roboto** fonts configured with `font-display: swap` to prevent Flash of Invisible Text (FOIT).
- **Responsive Design:** Adapts cleanly across desktop, tablet, and mobile viewports.
- **Modern Web Assets:** Uses an optimized `.avif` favicon (`img/favicon.avif`) and local Font Awesome icons for fast, reliable offline/online rendering.
- **Semantic & Accessible Markup:** Structured with `<header>`, `<nav>`, `<section>`, `<article>`, `<figure>`, `<figcaption>`, and `<footer>` landmarks.

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic elements & native `<details>`/`<summary>`)
- **Styling:** CSS3 (Custom Properties / CSS Variables, Flexbox, CSS Grid, Custom Utility Framework)
- **Typography:**
  - [EB Garamond](https://github.com/octaviopardo/EBGaramond12) — Classic serif variable font for headings and legal elegance (SIL OFL 1.1)
  - [Roboto](https://fonts.google.com/specimen/Roboto) — Clean sans-serif for body copy and UI elements (SIL OFL 1.1)
- **Icons:** [Font Awesome](https://fontawesome.com/) (`all.min.css`)

## 🚀 Getting Started

To run the project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/abdAlazez-99/LAW.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd LAW
   ```

3. **Open the project:**
   - Double-click `index.html` to open it directly in your browser, **or**
   - Launch it with **VS Code Live Server** for live reloading while customizing.
